## 📝 Descrição

A ABIAS é uma plataforma de crédito inteligente que combate o racismo algorítmico no sistema financeiro, focando exclusivamente no motoboy e entregador de aplicativo informal.

Em vez de punir o trabalhador pelo seu CEP ou pela falta de um holerite, a solução funciona em três pilares:

Score de Rodagem (IA Ética): Uma inteligência artificial que ignora a localização do usuário e calcula seu score analisando a consistência das suas entregas, quilometragem diária e avaliação nos aplicativos de mensagens e delivery (iFood, Uber, etc.).

Crédito Produtivo Carimbado: A plataforma libera microcrédito direcionado exclusivamente para a subsistência do negócio: troca de pneus, manutenção da moto e vouchers de combustível em oficinas e postos parceiros.

Risco Zero de Inadimplência: O pagamento do crédito é retido automaticamente em pequenas porcentagens direto dos repasses semanais que o entregador recebe das plataformas, blindando o ecossistema contra calotes.

## 💻 Execução dos projetos

Este projeto contém um notebook Jupyter que implementa e demonstra um modelo preditivo.
A seguir, estão descritos os requisitos e passos necessários para executar o notebook localmente (no VS Code).

**Requisitos:**

1.  Instalar o Python (versão 3.9 ou superior).
2. Instalar o Visual Studio Code (VS Code)
3. Dentro do VS Code, instalar as extensões:
-  Python (Microsoft)
- Jupyter (Microsoft)
4. Clonar este repositório ou baixar os arquivos do projeto:
    ```bash
    git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
    ``` 
5. Criar e ativar um ambiente virtual:
    ```bash
    python -m venv venv
    source venv/bin/activate   
    venv\Scripts\activate 
    ```
6. Instalar as dependências do projeto:
    ```bash
    pip install -r requirements.txt
    ```


**Execução:**

1. Abra o diretório do projeto no VS Code.
2. Abra o arquivo .ipynb (notebook Jupyter).
3. Selecione o interpretador Python do ambiente virtual.
4. Execute as células do notebook sequencialmente (Ctrl+Enter ou botão “Run All”).


**Execução da Aplicação web:**

A aplicação que permite rodar o modelo preditivo com interface gráfica, de forma simples e acessível.
Como acessar a aplicação: 

Rodando o Frontend

1. Acesse a pasta do frontend:

```bash
cd frontend
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

O frontend estará disponível em:
http://localhost:5173

Rodando o Backend

1. Acesse a pasta do backend:

```bash
cd backend
```

2. Crie e ative um ambiente virtual:

```bash
python -m venv venv
source venv/bin/activate     # Linux/Mac
venv\Scripts\activate        # Windows
```

3. Instale as dependências:

```bash

pip install -r requirements.txt
```

4. Rode o servidor FastAPI:

```bash
uvicorn app.main:app --reload
```

O backend estará disponível em:
http://127.0.0.1:8000
