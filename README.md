## 📝 Descrição

A ATVOS é uma companhia produtora de biocombustível, uma das maiores do setor sucroenergético no Brasil. Foi fundada em 2007 com a missão de produzir biocombustível e produtos a partir da cana-de-açúcar e sua biomassa para todo o país, sempre comprometida com o meio ambiente. Essa produção ocorre, atualmente, em 4 estados diferentes, o que acaba gerando uma alta demanda por transportes de insumos e matéria-prima por vias rodoviárias, ferroviárias, aéreas e dutoviárias.

Levando em consideração o fato que os valores de transporte variam de forma diretamente proporcional a diversos fatores sazonais, internos e externos, esses custos acabam por ser altamente momentâneos em boa parte dos casos afetando o custo final da empresa. Tal problemática afeta diretamente toda a sua cadeia de produção e também os valores finais dos seus produtos. A proposta central do projeto gira em torno dessa problemática, que deverá trazer uma base de apoio para decisões mais assertivas, lucrativas e estratégicas para a companhia, a fim de trazer uma melhoria nos resultados.

Aqui o vídeo de demonstração da plataforma de visualização: https://www.youtube.com/watch?v=6EgMTrq9Q3I

## 💻 Execução dos projetos

Este projeto contém um notebook Jupyter que implementa e demonstra um modelo preditivo.
A seguir, estão descritos os requisitos e passos necessários para executar o notebook localmente (no VS Code).

**Requisitos:**

1.  Instalar o Python (versão 3.9 ou superior).
2. Instalar o Visual Studio Code (VS Code)
3. Dentro do VS Code, instalar as extensões:
-  Python (Microsoft)
- Jupyter (Microsoft)
4. Clonar este repositório ou baixar os arquivos do projeto:
    ```bash
    git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
    ``` 
5. Criar e ativar um ambiente virtual:
    ```bash
    python -m venv venv
    source venv/bin/activate   
    venv\Scripts\activate 
    ```
6. Instalar as dependências do projeto:
    ```bash
    pip install -r requirements.txt
    ```


**Execução:**

1. Abra o diretório do projeto no VS Code.
2. Abra o arquivo .ipynb (notebook Jupyter).
3. Selecione o interpretador Python do ambiente virtual.
4. Execute as células do notebook sequencialmente (Ctrl+Enter ou botão “Run All”).


**Execução da Aplicação web:**

A aplicação que permite rodar o modelo preditivo com interface gráfica, de forma simples e acessível.
Como acessar a aplicação: 

Rodando o Frontend

1. Acesse a pasta do frontend:

```bash
cd frontend
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

O frontend estará disponível em:
http://localhost:5173

Rodando o Backend

1. Acesse a pasta do backend:

```bash
cd backend
```

2. Crie e ative um ambiente virtual:

```bash
python -m venv venv
source venv/bin/activate     # Linux/Mac
venv\Scripts\activate        # Windows
```

3. Instale as dependências:

```bash

pip install -r requirements.txt
```

4. Rode o servidor FastAPI:

```bash
uvicorn app.main:app --reload
```

O backend estará disponível em:
http://127.0.0.1:8000
