# Público-Alvo, Persona e Jornada

Para criar uma infraestrutura financeira verdadeiramente inclusiva, o **Abias** foi desenhado a partir da realidade vivida nas ruas. Entender o usuário não se limita a analisar dados de renda; exige mapear a rotina exaustiva, os medos em relação ao sistema bancário e os mecanismos informais de sobrevivência econômica de quem entrega a cidade todos os dias.

## Por que o recorte importa

O mercado de entregadores de aplicativo no Brasil tem 1,5 milhão de trabalhadores ativos. **68% deles são pretos ou pardos.** Esse número não é contexto — é o núcleo da proposta do Abias.

A exclusão financeira não é uniforme. Ela é mais intensa exatamente para quem mais precisa de acesso a crédito: trabalhadores negros, periféricos, sem vínculo empregatício formal. O sistema bancário tradicional não falhou por acidente com esse perfil — ele foi construído para servir outro perfil.

O Abias foi construído para servir esse.
